# Contributing to Observability-QE Framework

We welcome contributions to improve quality measurement!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/new-dashboard`)
3. Commit your changes (`git commit -m 'Add new Grafana dashboard'`)
4. Push to the branch (`git push origin feature/new-dashboard`)
5. Open a Pull Request

## Contribution Guidelines

- Ensure dashboard JSONs are exported with relative variables (avoid hardcoded IDs).
- Provide a screenshot of any new dashboards in the PR.
- Scripts should be well-documented and follow Python PEP 8.
